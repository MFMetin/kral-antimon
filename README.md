# 👑 Kral Antimon

My personal League of Legends profile page — a single-page "link in bio" site
for my account **Antimon#tilt** on the TR server.

**Live:** https://mfmetin.github.io/kral-antimon/

## What's on it

- A golden arrow-rain background animation
- The **Kral Antimon** title, revealed letter by letter
- A click-to-enter screen with background music
- My live ranked stats: Solo/Duo and Flex tier, LP and win rate
- The champions I've played most in my recent ranked games
- Links to my socials

Rank data refreshes automatically, so the page always shows where I currently
stand.
